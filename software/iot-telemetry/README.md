# IoT Telemetry Dashboard

Real-time sensor monitoring and visualization dashboard.

## Overview

A web-based dashboard for monitoring IoT sensor data in real-time, displaying metrics such as CPU, RAM, and GPU usage from connected devices.

## Features

- Real-time telemetry visualization
- Serial/USB data ingestion from microcontrollers
- Historical data logging
- Alert notifications for threshold violations

## Tech Stack

- **Frontend**: JavaScript/TypeScript
- **Data Format**: JSON over serial
- **Visualization**: Charts and graphs

## Related Projects

This dashboard receives data from embedded firmware projects like [Croc OS](../../hardware/croc-os/), which sends ArduinoJson telemetry over serial.
